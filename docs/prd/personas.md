# Personas

Parent: [./readme.md](./readme.md) · Up: [../README.md](../README.md)

## Primary User — The Gym Beginner

- **Context**: Just started gym, following a fixed routine
- **Need**: Log workouts quickly without thinking too much
- **Pain**: Existing apps are bloated with features they don't need
- **Device**: Phone (primary) or desktop
- **Frequency**: 5 days/week

## Family Group

- **Context**: Siblings starting gym together
- **Need**: See each other's progress for motivation
- **Pain**: No easy way to compare without sharing phones
- **Privacy**: Stats are public within family, photos are private

## Phase 2 — Growing Lifter

- **Context**: Has trained for months, outgrew the fixed routine, compares the app with Hevy/Gravl
- **Need**: Build own routines, know how much to add next session, see records and stats, train when there is no signal
- **Pain**: "¿Cuánto subo hoy?", stalled lifts with no guidance, a routine tied to weekdays
- **Device**: Phone in the gym (one-handed, often offline), desktop for building routines
